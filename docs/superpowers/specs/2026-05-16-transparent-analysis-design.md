# 透明化分析设计文档

> **日期：** 2026-05-16 | **状态：** 设计完成，待实现

## 一、目标

让用户看到 AI 理财系统"为什么得出这个结论"，通过**展示思考过程**建立信任。分两个阶段：

1. **生成时** — Agent 工作台：实时展示每个 Agent 的计算步骤
2. **生成后** — 概览+详情双视图：左侧结论、右侧完整计算链路

---

## 二、测评双模式

### 2.1 简单模式（默认）

保持 5 字段（年龄/收入/支出/风险偏好/投资期限）快速通关。未填字段使用默认值：

| 字段 | 默认值 | 展示方式 |
|------|--------|---------|
| 存款/可投资资产 | 收入×12×0.3 | "估算值" |
| 月度负债 | 0 | "未知，按0计算" |
| 保险配置 | false | "未知，按未配置计算" |

### 2.2 完整模式（可展开）

在 Step 2（投资偏好）下方增加可折叠的"详细财务信息"区域：

| 字段 | 类型 | 说明 |
|------|------|------|
| 已有存款/投资 | 数字输入 | 已存下的钱+已投资的金额 |
| 月度负债 | 数字输入 | 房贷/车贷/信用卡月还款 |
| 是否配置保险 | 开关 | 重疾险/医疗险等 |

### 2.3 交互

- 默认处简单模式，底部提示"想获得更精准的分析？[展开完整财务信息]"
- 展开后字段显示，填入后自动替代默认值
- 简单/完整切换不丢失已填数据

## 三、生成时：Agent 工作台

替换当前 4 步进度条，改为每个 Agent 一张实时卡片。

### 3.1 整体结构

```
┌─ Agent 工作台 ──────────────────────────────┐
│  🕐 总耗时: 68.4s                            │
│                                              │
│  Profile Agent  ✅ 12.3s   [展开/折叠]       │
│  ├ 📥 读取数据 (5+3字段)                     │
│  ├ 📊 计算核心指标 (储蓄率/应急月/负债率)     │
│  ├ 🧮 计算健康分 (4维公式代入)               │
│  ├ 🏷 判定标签 (生命周期/投资风格)           │
│  └ ✍️ AI生成总结...                          │
│                                              │
│  Market Agent   ✅ 18.7s   [展开已折叠]      │
│                                              │
│  Strategy Agent ✅ 30.2s   [展开已折叠]      │
│                                              │
│  Coaching Agent ✅ 7.2s    [展开已折叠]      │
└──────────────────────────────────────────────┘
```

### 3.2 交互规则

- 当前活跃 Agent 自动展开，显示实时进度
- 完成的 Agent 自动折叠（节省空间），折叠后显示 ✅ + 耗时
- 每个步骤完成带 ✓ 动画
- 每一步显示该步的实际耗时

### 3.3 数据来源

Agent 工作台的内容来自 graph 节点的 `_update_progress()` 写入 `user_states` 的实时数据。每个节点完成时写入该节点的 `computation_steps` 数组。

**数据流：**
```
Agent 执行 → computation_steps 写入 user_states
  → 前端轮询 /status → AgentWorkbench 实时渲染
  → 生成完成后 → computation_steps 随策略持久化到 DB
  → 用户回访时 → 详情面板从 DB 加载 computation_steps
```

`computation_steps` 同一次生成在两种视图间复用：工作台读取展示进度，详情面板读取展示完整链路。前后端使用同一 JSON 结构，无需重复定义。

## 四、生成后：概览 + 详情双视图

### 4.1 布局

```
┌──────────────────────────────────────────────────────┐
│ 📊 分析结果                          [⬇ 收起详情]    │
├──────────────────────┬───────────────────────────────┤
│ 左侧：概览面板        │ 右侧：详情面板                │
│ (占40%)              │ (占60%)                       │
│                      │                               │
│ 4个模块卡片：         │ 当前查看: 📍 健康分 100       │
│ 🧑 用户画像   🟡     │                               │
│ 📈 市场研判   🟢     │ ① 输入数据                    │
│ 📊 配置方案   🟡     │ ② 计算过程                    │
│ 💡 督导建议   🔵     │ ③ 判定规则                    │
│                      │ ④ 数据溯源                    │
│                      │                               │
└──────────────────────┴───────────────────────────────┘
```

### 4.2 交互

- 点击左侧概览中任意指标 → 右侧切换对应详情
- 被点击的指标高亮（蓝色边框），表示"当前查看"
- 移动端：详情改为底部抽屉，上滑弹出
- 详情面板右上角 [⬇ 收起] 可折叠整个详情区域

### 4.3 详情内容模板

每个指标必须包含：
- **输入数据**：原始值从哪来（用户/系统/AKShare）
- **计算过程**：公式代入 + 中间值
- **判定逻辑**：为什么得出这个结论
- **数据来源**：标注具体出处
- **可信度**：🟢计算值 / 🟡推算值 / 🔵AI生成

## 五、各 Agent 详情内容

### 5.1 Profile Agent

| 可点击指标 | 详情内容 |
|-----------|---------|
| 财务健康分 | 4维公式逐项计算（储蓄力/应急力/投资力/保障力） |
| 生命周期 | 年龄判定规则 (<35/35-50/>50) + 解释 |
| 投资风格 | 风险等级+年龄 → 9宫格矩阵映射结果 |
| 优劣势 | 每个标签对应的数据触发条件 |
| 储蓄率 | 计算公式: (收入-支出)/收入×100% |
| 应急月数 | 计算公式: 可投资资产/月支出 |

### 5.2 Market Agent

详情模板：`原始行情 → 统计计算 → 估值分析 → 宏观指标 → AI生成`

```
📍 权益预期收益率：8.2%

① 原始数据
  标的     沪深300 (sh000300)
  时间范围  2021-05 ~ 2026-05 (5年)
  数据点数  1,217 个交易日
  数据源    AKShare → 东方财富

② 统计计算
  日均收益率 = mean(日涨跌幅) = 0.0325%
  年化收益率 = 0.0325% × 252 = 8.2%
  日波动率 = std(日涨跌幅) = 1.17%
  年化波动率 = 1.17% × √252 = 18.5%
  最大回撤 = min(累积收益曲线) = -30.2%
  Sharpe = (8.2% - 2.65%) / 18.5% = 0.30

③ PE估值
  当前PE(TTM)          13.82
  近5年PE区间          [9.52, 14.80]
  当前分位             95% → 偏高
  ERP = 1/13.82 - 2.65% = 4.0% → 有一定吸引力

④ 宏观指标
  PMI     50.2    AKShare(统计局)  2026-04
  CPI     0.4%    AKShare(统计局)  2026-04
  M2增速  10.5%   AKShare(央行)    2026-04
  社融    3.5万亿 AKShare(央行)    2026-04

⑤ AI生成
  🔵 风险因素列表 — DeepSeek LLM 基于以上量化数据生成
  🔵 整体建议 — DeepSeek LLM 基于以上量化数据生成
  
  数据源标注: 行情→东方财富 | PE→东方财富 | 债券→中债登 |
  宏观→国家统计局/央行。AKShare为数据聚合器，非原始来源。
```

### 5.3 Strategy Agent

详情模板：`映射规则 → 约束校验 → 假设说明`

```
📍 四笔钱比例：活钱10% 稳健30% 长期50% 保障10%

① 生成方式
  基于用户画像(风险=medium, 年龄=32) + 市场研判(ERP=4.0%)
  → DeepSeek LLM 生成初始比例

② 适当性校验
  风险等级 medium → 权益上限 60%
  LLM输出 growth=50% ≤ 60% → 通过（无需截断）

③ 压力测试
  2015年股灾: -15% (沪深300实际跌幅-43%,
            但四笔钱组合因债底和现金缓冲损失较小)
  2020年疫情: -12% (同上，恢复期3-4个月)
  方法: 历史情景映射，非AI推测

④ 再平衡规则
  偏离阈值 5% — 行业惯例
  检查频率 季度 — 标准配置
  并非以历史回测最优值，而是普适性规则
``` |

### 5.4 Coaching Agent

| 可点击指标 | 详情内容 |
|-----------|---------|
| 督导建议 | LLM生成文本，基于已计算的全部量化数据 |

## 六、市场研判增强

### 6.1 新增宏观指标

在现有 4 项基础上增加：

| 指标 | AKShare 接口 | 数据源机构 |
|------|-------------|-----------|
| PMI | `macro_china_pmi` | 国家统计局 |
| M2增速 | `macro_china_money_supply` | 中国人民银行 |
| 社融增量 | `macro_china_social_financing` | 中国人民银行 |

### 6.2 数据源标注

每个指标在详情面板中明确标注：
- 原始数据机构（国家统计局/央行/中债登/东方财富）
- AKShare 抓取时间戳
- 是否为实时数据还是历史最近值

### 6.3 降级策略

PMI/M2/社融任一获取失败时：
- 详情面板中该指标显示"数据暂缺"
- 不阻断整体流程，其他指标正常展示
- LLM prompt 中省略该指标，不编造数据
- 现有 4 项（沪深300/创业板/国债/CPI）的降级策略保持不变（回退硬编码默认值）
