# 产品蓝图：多 Agent 智能理财规划系统

## 用户画像
25-45岁，有稳定收入，理财知识有限，希望"傻瓜式"管理资产
核心需求：知道钱该怎么分配、市场不好时有人安抚、看到资产在增值

---

## 信息架构

```
导航栏
├── 🏠 首页仪表盘     — 打开第一眼的总览
├── 📊 我的方案       — 四笔钱配置详情 + 持仓
├── 💬 AI助手         — 对话式互动
├── 📈 市场观察       — 行情 + 研判
└── 👤 我的           — 设置 + 历史
```

## 四、视觉设计方向

### 配色方案
- 主色：#3B82F6 (信任蓝) 
- 活钱：#10B981 (绿 - 流动性好)
- 稳健：#3B82F6 (蓝 - 稳定可靠)
- 长期：#F59E0B (金/橙 - 增值)
- 保障：#EF4444 (红 - 重要保护)
- 背景：浅灰 #F8FAFC

### 设计语言
- 卡片式布局，大圆角 (12px)
- 数字要大（资产金额 36px+）
- 涨跌用红绿色（国内习惯：红涨绿跌）
- 移动端优先，响应式适配
