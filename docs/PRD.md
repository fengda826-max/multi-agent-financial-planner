# 产品需求文档：智能理财规划系统

> **版本：** v1.1 | **日期：** 2026-05-16

---

## 一、产品概述

### 1.1 我们解决什么问题

大多数人对理财感到困惑：钱该怎么分配？什么时候该调整？市场跌了怎么办？他们要么凭感觉操作，要么把钱放银行贬值。专业理财顾问费用高昂（年费数千元起），普通人用不起。

这个产品让用户花 5 分钟回答几个简单问题，就能得到一份基于 AI 分析的个性化资产配置方案——而且是活的，会持续陪伴和提醒。

### 1.2 核心价值主张

**对用户来说，这个产品做三件事：**

1. **告诉我钱该怎么分配** — 基于我的收入和风险偏好，生成四笔钱（活钱/稳健/长期/保障）配置方案
2. **别让我干等** — 生成过程逐步展示分析结果，我能看到每一步在做什么
3. **陪我走下去** — 不是一次性报告。市场变了提醒我，我有问题随时问 AI 助手

### 1.3 目标用户

| 用户类型 | 特征 | 核心诉求 |
|----------|------|----------|
| 理财新手 (25-30岁) | 刚工作，月入1-2万，不懂投资 | "告诉我钱该放哪" |
| 中产白领 (30-40岁) | 有一定积蓄，想增值但怕亏 | "怎么平衡风险和收益" |
| 家庭支柱 (35-45岁) | 有房贷/育儿压力，需要保障 | "家里万一出事怎么办" |

## 二、用户故事

### 2.1 首次使用

> **小明，28岁，程序员，月入2万，从来没理过财。**

小明听同事推荐注册了产品。首页告诉他"还没测评"并引导他回答几个问题：

1. 年龄（28）
2. 月收入和支出（收入20000，支出12000）
3. 风险偏好（他选了"稳健型"——不太懂，保守一点）
4. 投资期限（5年——短期不需要用钱）

点击"生成方案"后，他没有干等——页面立即跳转，他先看到自己的财务分析（"积累期，月结余8000，储蓄率40%，财务健康85分"），然后是市场分析（"当前权益预期收益8%，债券3.5%"），接着四笔钱方案（活钱10%/稳健30%/长期50%/保障10%）和饼图。整个过程约 80 秒，每一步都能看到进度。

小明看完方案，点击"咨询AI助手"问："为什么长期占了50%？"AI 告诉他因为他年轻、收入稳定，可以承受短期波动换取长期复利。

### 2.2 回访使用

> **过了两周，小明又登录了。**

首页仪表盘显示他的健康分、总资产（可投资资产+月结余推算）、资产配置饼图。他点击"我的方案"查看详情，然后去"市场观察"看看最新的 AI 研判。

他注意到最近沪深300跌了，去问 AI："市场下跌对我的方案有影响吗？"AI 安抚他说短期波动正常，压力测试显示极端情况也能在几个月内恢复。

## 三、功能需求

### 3.1 注册与登录

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| A1 | 注册 | 输入用户名和密码即可创建账号，邮箱选填 | P0 |
| A2 | 登录 | 用户名+密码登录，获得 JWT 令牌 | P0 |
| A3 | 自动登录 | 令牌有效期内无需重新登录 | P0 |

### 3.2 风险测评

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|

| B2 | 基本信息 | 输入年龄、月收入、月支出 | P0 |
| B3 | 投资偏好 | 选择风险偏好（保守/稳健/进取）、投资期限（1年/3年/5年/10年+） | P0 |

| B5 | 默认值 | 表单预填合理默认值，用户可快速提交 | P1 |

### 3.3 策略方案生成

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|

| C2 | 渐进式披露 | 生成过程中逐步展示：用户画像 → 市场研判 → 配置方案 → 督导建议 | P0 |
| C3 | 进度指示 | 顶部 4 步进度条，实时显示当前正在分析什么 | P0 |

## 四、非功能性需求

### 4.1 性能

- 策略生成全流程不超过 120 秒（4个 Agent 依次调用 LLM）
- 页面首次加载不超过 3 秒
- 对话回复不超过 15 秒

### 4.2 可用性

- 所有页面有空状态引导（无数据时不白屏）
- 测评表单预填默认值，无需每次重新填写
- 错误提示用中文，告知用户发生了什么和怎么办

### 4.3 数据

- 市场数据优先使用 AKShare 实时数据
- 数据源不可用时使用预设默认值，不影响正常使用
- 用户数据（账号、测评、方案）持久化到数据库，重启不丢失

### 4.4 安全

- 密码使用 bcrypt 加密存储
- API 使用 JWT 令牌鉴权
- 未登录用户无法访问功能页面

## 五、用户界面

### 5.1 信息架构

```
导航栏
├── 🏠 首页     — 仪表盘总览
├── 📊 我的方案 — 方案详情
├── 💬 AI助手  — 对话咨询
├── 📈 市场观察 — 行情研判
└── 👤 我的     — 个人中心
```

### 5.2 设计原则

- **一眼看懂**：关键数字要大（资产金额、百分比），用图表代替表格
- **逐步深入**：首页概览 → 点击进入详情 → AI 对话深入解读
- **温暖专业**：紫色+蓝色主调，圆角卡片，营造信任感
- **国内习惯**：红涨绿跌，金额用万做单位
